# 🧱 블록 요소와 인라인 요소

## 정리

HTML 요소는 CSS `display` 값에 따라 화면에 배치된다. 브라우저 기본 스타일에서 많은 요소는 `block` 또는 `inline`으로 표시된다.

### 블록 요소

- 블록 요소는 보통 앞뒤 요소와 다른 줄에 배치된다.
- 별도 너비를 지정하지 않으면 부모가 제공하는 가로 공간을 채운다.
- `width`, `height`, `margin`, `padding`을 적용할 수 있다.
- `div`, `p`, `h1`~`h6`, `ul`, `ol`, `li`는 기본적으로 블록처럼 표시되는 대표적인 요소다.
- `header`, `footer`, `article`, `aside` 같은 시맨틱 요소는 콘텐츠의 구조와 의미를 나타낸다.

### 인라인 요소

- 인라인 요소는 텍스트 흐름 안에서 다른 인라인 요소와 나란히 배치된다.
- 콘텐츠 크기만큼의 공간을 차지하고, 공간이 부족하면 텍스트처럼 다음 줄로 이어진다.
- 일반적인 인라인 요소는 `width`, `height`를 지정해도 레이아웃 크기에 적용되지 않는다.
- 상하 `margin`은 줄의 레이아웃에 영향을 주지 않는다. 상하 `padding`은 적용되어 배경이나 테두리가 보일 수 있지만, 일반적으로 줄의 높이를 늘리지는 않는다.
- `span`, `a`, `strong`, `em`은 기본적으로 인라인처럼 표시되는 대표적인 요소다.

### `img`의 예외

- `img`는 기본 `display` 값이 `inline`이지만, 대체 요소(replaced element)이므로 `width`와 `height`를 지정할 수 있다.
- 따라서 `img`가 `inline-block`인 것은 아니다.

### 사용할 때

- 큰 영역을 구분하거나 콘텐츠 덩어리를 배치할 때는 블록 형태의 요소를 사용한다.
- 문장 안 일부를 강조하거나 링크처럼 텍스트 흐름 안에 기능을 부여할 때는 인라인 형태의 요소를 사용한다.
- 요소는 먼저 의미에 맞게 선택하고, 필요한 배치 방식은 CSS `display`로 조정한다.

## 요약

- 블록 요소는 보통 새 줄에 배치되고, 부모의 가로 공간을 채운다.
- 인라인 요소는 콘텐츠 크기만 차지하며 텍스트 흐름 안에 배치된다.
- 블록/인라인 배치 방식은 CSS `display`로 바꿀 수 있다.
- 일반 인라인 요소에는 `width`, `height`가 레이아웃 크기에 적용되지 않지만, `img` 같은 대체 요소는 예외다.

## 질문

### Q1. HTML 요소에서 블록 요소와 인라인 요소의 차이점은 무엇인가요?

- 블록 요소는 보통 새 줄에 배치되고, 별도 너비를 지정하지 않으면 부모가 제공하는 가로 공간을 차지합니다. `width`, `height`, `margin`, `padding`도 적용할 수 있습니다.
- 인라인 요소는 한 줄 안에서 다른 텍스트 및 인라인 요소와 함께 배치되며 콘텐츠 크기만큼의 공간을 차지합니다. 일반적인 인라인 요소는 `width`, `height`가 레이아웃 크기에 적용되지 않고, 상하 `margin`도 줄의 레이아웃에 영향을 주지 않습니다.
- 이 배치 방식은 주로 CSS `display` 속성으로 결정됩니다.

### Q2. 웹 페이지 레이아웃을 설계할 때 블록 요소와 인라인 요소를 언제 사용하나요?

- 페이지의 한 부분처럼 큰 영역을 구분하고 배치할 때는 블록 형태의 요소를 사용합니다.
- 문장 안의 일부 텍스트를 강조하거나 링크처럼 특정 기능을 부여할 때는 인라인 형태의 요소를 사용합니다.
- 단, 요소는 레이아웃만 보고 고르기보다 콘텐츠의 의미에 맞게 먼저 선택하고, 배치 방식은 CSS로 조정합니다.

# `<head>` 안에 들어가는 태그

## 잘 알고 있는지

- 🥺

## 답을 본 뒤 알게 된 것

웹 페이지는 크게 두 부분으로 나뉜다. 사용자에게 직접 보이는 Body 태그와 화면에 보이지 않는 곳에서 웹 사이트를 제어하는 head 태그.

### head 태그는 웹 사이트 설명서

웹 브라우저에 문서의 특징, 필요한 파일, 해석 기준을 알려 주는 설명서로, 웹 사이트의 정체성을 정의하는 메타데이터를 담는 공간이다.

화면에는 보이지 않지만 웹 사이트의 동작과 검색 엔진 최적화에 아주 결정적인 역할을 한다.

< head > 태그 안에 주로 사용하는 태그인 title, meta, link, style, script 5가지를 주제로 공부한다.

### title 태그는 웹 사이트 이름표

웹 브라우저의 탭이나 즐겨찾기에 표시되는 웹 사이트의 제목을 정의한다. 이 정보는 검색 엔진이 웹 사이트의 주제를 파악하는 데에 사용된다.

```js
<title>내 페이지</title>
```

### meta 태그는 웹 사이트 상세정보

< meta > 태그는 웹 사이트의 다양한 정보를 담을 수 있는 만능 태그로, 속성에 따라 웹 브라우저나 검색 엔진이 웹 사이트를 어떻게 이해할 지 결정한다.

대표적인 속성으로 viewport, description, og 등이 있다.

< meta > 태그와 관련된 중요한 정보는 다음과 같다.

#### 문자 인코딩

```js
<meta charset="UTF-8">
```

문자 인코딩을 UTF-8로 지정해야 한글을 포함한 여러 나라의 언어가 깨지지 않고 표시된다.

#### 뷰포트 설정

```js
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

다양한 기기에서 웹 사이트의 너비나 배율을 어떻게 표시할 지 결정한다.

이 설정이 없으면 PC 화면이 그대로 축소된 채 모바일에 나타난다.

#### 웹 사이트 요약

```js
<meta name="description" content="페이지 설명">
```

구글 검색 결과에서 제목 아래에 표시되는 문구가 바로 description 속성이다.

사용자가 웹 사이트의 내용을 빠르게 파악하는 데에 도움이 되며 클릭을 유도하는 데 아주 중요한 역할을 한다.

#### 작성자 정보

```js
<meta naem="author" content="작성자">
```

페이지의 작성자 정보를 담는다. 검색 엔진이나 문서 도구에서 웹 사이트의 소유자를 확인할 때 사용한다.

#### 미리 보기

```js
<meta property="og:type" content="article">
```

카카오톡이나 페이스북, 트위터와 같은 소셜 미디어에서 웹 사이트 링크를 공유했을 때 해당 웹 사이트의 제목, 설명, 대표 이미지 등이 표시되도록 설정하는 기능.

### link 태그는 외부 파일 연결

웹 사이트는 html만으로 완성되지 않는다. 디자인을 담당하는 css 파일, 파비콘 파일 등 외부에서 가져와 연결해 사용해야 하는 요소가 많다.

이런 외부 리소스를 html 문서와 연결할 때 link 태그를 사용한다.

#### css 파일 연결

```html
<link rel="stylesheet" href="style.css" />
```

외부 css 파일을 연결해 웹 페이지의 디자인과 레이아웃을 꾸밀 때 사용하는 태그.

rel은 relationship의 줄임말로, 연결하는 파일의 종류를 웹 브라우저에 알려준다.

#### 파비콘 설정

```html
<link rel="icon" href="favicon.ico" />
```

웹 브라우저 탭에 표시되는 파비콘을 설정할 때 사용한다.

### style 태그는 내부 스타일 시트

```html
<style>
  p {
    color: blue;
  }
</style>
```

style 태그는 HTML 문서 안에서 CSS 코드를 직접 작성하고 싶을 때 사용한다.

실무에서는 css 파일을 따로 작성하고 link 태그로 연결하는 방식이 더 자주 사용된다.

### script 태그는 자바스크립트 연결

script 태그는 웹 페이지에 동적인 기능을 추가하는 자바스크립트 파일을 연결하거나 태그 내부에 코드를 직접 작성할 때 사용한다.

</ body > 태그 직전에 script 태그를 배치하면 HTML 구조를 먼저 읽고 자바스크립트 코드를 실행하여 런타임 성능을 개선할 수 있다.

또한, script 태그 내부에 자바스크립트 코드를 직접 작성해 간단한 기능을 빠르게 테스트하는 것도 가능하다.

### 정리

〈 head 〉 태그는 웹 사이트의 메타데이터를 담아 웹 브라우저와 검색 엔진에 페이지의 성격과 동작 방식을 알려 주는 역할을 한다. 〈 head 〉 태그 안에는 웹 페이지의 제목을 정의하는 title, 문자 인코딩과 설명 등을 설정하는 meta, 외부 파일을 연결하는 link, 내부 스타일을 지정하는 style, 스크립트를 추가하는 script 등이 포함된다. head 태그는 겉으로 보이지 않지만 성능 최적화, 검색 엔진 최적화, 크로스 플랫폼 호환성 확보에 매우 중요하다.

## 질문

Q. head 태그 안에 주로 사용되는 title, meta, link, style, script는 각각 어떤 역할을 하나요?

A. title은 웹 페이지의 제목을, meta는 웹 페이지의 정보를 알립니다. link는 css 파일이나 파비콘 등 외부의 것을 html에 나타낼 때 사용하며, style은 css 속성을 html 파일 안에 직접 정의하고자 할때 사용합니다. script는 자바스크립트 코드를 사용하기 위해 작성합니다.

Q. head 태그의 설정은 검색 엔진 최적화와 사용자 경험(UX)에 왜 중요한 영향을 미치나요?

A. head 태그는 겉으로 크게 드러나는 것은 아니지만 사이트의 메타데이터를 담아 웹 브라우저와 검색 엔진에 페이지의 성격과 동작 방식을 알려주기 때문입니다.

(보충:
SEO 측면에서는 title과 meta description이 검색 결과에 그대로 노출되어 클릭률에 영향을 주고,
og 태그는 SNS 공유 시 표시되는 미리보기를 결정합니다.
canonical 링크는 중복 URL 중 대표 페이지를 지정해 색인이 분산되는 것을 방지합니다.

UX 측면에서는 meta viewport 설정이 없으면 모바일에서 데스크톱 레이아웃이 축소되어 표시되고,
charset 선언이 누락되면 한글이 깨질 수 있습니다.
또한 link의 preconnect나 preload로 리소스 우선순위를 조정해 초기 로딩 성능을 개선할 수 있습니다.)

Q. meta charset은 왜 head 최상단에 위치해야 하나요?

A. 브라우저는 인코딩을 확정하기 전까지 바이트를 어떻게 해석할지 알 수 없기 때문입니다.
명세상 charset 선언은 문서의 처음 1024바이트 안에 있어야 하며,
그 이후에 선언되면 브라우저가 이미 잘못된 인코딩으로 파싱을 시작해 되돌리는 비용이 발생합니다.

Q. meta viewport의 width=device-width, initial-scale=1은 각각 어떤 의미인가요?

A. width=device-width는 뷰포트 너비를 기기의 화면 너비에 맞추라는 의미입니다.
이 설정이 없으면 모바일 브라우저는 기본값인 980px 기준으로 레이아웃을 구성한 뒤 축소해 보여줍니다.
initial-scale=1은 페이지 최초 로드 시의 확대 배율을 1배로 고정합니다.

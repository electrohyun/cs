## 답을 본 뒤 알게 된 것

### 시맨틱 태그란

- 과거에는 웹 사이트 구조 대부분을 div를 이용해 만들었다. 가령 이것처럼...

```html
<div id="header"></div>
```

- 구조만 존재할 뿐 태그의 정보는 전달하지 못했다.

- 그러나 HTML5가 등장하면서 의미를 지닌 시맨틱 태그가 표준으로 자리를 잡았다.
- 시맨틱 태그란, '이름만으로도 콘텐츠의 역할과 의미를 명확하게 전달하는 HTML 태그'를 일컫는다.

### 시맨틱 태그 종류

- header: 웹 사이트나 특정 세션의 머리말을 나타낸다. 로고, 제목, 검색 창 등의 정보가 들어간다.
- footer: 웹 사이트나 특정 섹션의 꼬리말을 나타낸다. 저작권 정보, 연락처 등 부가 정보가 들어간다.
- nav: 다른 웹 사이트로 이동하기 위한 내비게이션 문구를 묶을 때 사용한다.
- main: 문서의 핵심 콘텐츠를 담는다. 이 태그는 문서에 단 한 번만 사용한다.
- article: 블로그 글, 뉴스 기사 등 독립적인 콘텐츠를 담는다.
- section: 연관 콘텐츠를 그룹화할 때 사용한다. 보통 제목(heading)을 함께 포함한다.
- aside: 사이드바나 광고 등 문서의 주요 내용과 간접적으로 연관된 정보를 담는다.

### 시맨틱 태그의 역할

- 의미가 담긴 태그를 왜 사용해야 할까?

1. 검색 엔진 최적화

- 구글이나 네이버 같은 검색 엔진은 크롤러 같은 robot을 통해 웹 사이트의 정보를 수집한다.
- 이 로봇은 div 태그로만 구성된 웹 사이트보다 시맨틱 태그를 활용한 구조를 훨씬 더 정확히 이해한다.
- 검색 엔진은 main 태그와 article 태그로 작성된 내용을 핵심 컨텐츠로 분류하고 가중치를 부여할 수 있다.
- 이는 웹 사이트가 검색 결과 상단에 노출될 확률을 높여준다.

2. 웹 접근성 향상

- 시각 장애인은 화면의 내용을 음성으로 읽어주는 스크린 리더라는 프로그램을 사용한다.
- 시맨틱 태그는 스크린 리더가 페이지의 구조를 파악하는 데 중요한 역할을 한다.
- 예를 들어, 스크린 리더는 nav 태그를 만나면 "여기는 내비게이션 태그입니다"라고 알려줄 수 있다.

3. 코드의 가독성과 유지보수 효율 향상

- 시맨틱 태그로 잘 짜인 코드는 개발자를 위한 최고의 구조 설명서가 된다.
- 수많은 div 태그들 사이에서 id나 class 이름을 일일이 확인하지 않아도 태그 이름만 보고도 문서의 구조를 빠르게 파악할 수 있다.
- 시맨틱 태그를 사용하는 일은 코드를 예쁘게 만드는 작업만이 아니라, 스크린 리더, 검색 엔진, 동료 개발자까지 모두가 이해하기 쉬운 웹을 만드는 중요한 설계 요소이다.

### 정리

- 시맨틱 태그는 콘텐츠의 의미를 정확히 전달하기 위한 HTML 태그입니다.
- div 태그와 달리 header footer main 과 같은 태그는 웹 페이지의 구조와 역할을 명확히 설명한다.
- 그 결과 검색 엔진 최적화가 향상되고, 스크린 리더가 구조를 쉽게 이해할 수 있게 됨으로써 웹 접근성이 향상됩니다.
- 또한 코드의 가독성과 유지보수성도 높아져 효율적인 웹 개발 환경을 제공합니다.

## 질문

- Q. header, main, article과 같은 시맨틱 태그를 사용하면 검색 엔진 최적화와 웹 접근성에 어떤 이점이 있을까요?

- A. 시맨틱 태그를 활용함으로서 검색 엔진은 해당 내용을 핵심 콘텐츠로 분류하여 가중치를 줄 수 있고, 또 스크린 리더가 페이지의 구조를 이해하는 데에 도움을 주어 시각 장애인이 스크린 리더를 통해 웹 페이지를 이해하는 데에 도움을 줌으로써 웹 접근성 또한 향상된다는 이점을 갖습니다.

- Q. div 태그 대신 시맨틱 태그를 사용하는 것이 코드 가독성과 유지보수성 측면에서 왜 더 유리할까요?
- 시맨틱 태그를 활용하지 않는 경우 div 태그로 HTML 요소들을 묶어 사용하게 되는데, 이 경우보다 header, footer, article, aside와 같은 태그로 나타냄으로서 검색 엔진, 스크린 리더는 물론 같은 개발자 입장에서도 구조를 한번에 파악하고 찾아내기가 용이하기 때문에 코드 가독성에 있어서도, 유지보수성에 있어서도 유리하다고 볼 수 있습니다.

# 🏷️ HTML 종료 태그

## 정리

- 모든 HTML에 종료 태그가 있는 것은 아니다.

### 빈 태그 작성법

- 종료 태그가 필요없는 태그를 빈 태그라고 일컫는다. (void elements / empty elements)
- 이름 그대로 내부에 텍스트나 다른 태그같은 콘텐츠를 포함할 수 없는 태그이다.
- 빈 태그는 문서에 무언가를 추시하거나 표시하는 역할이다.

#### img 태그

```html
<img src="logo.png" alt="우리 회사 로고" />
```

- 이미지를 삽입하는 태그이다. src 속성에 이미지 경로를 alt 속성에 대체 텍스트를 지정한다.

#### br 태그

```html
<p>
  줄입니다. <br />
  줄바꾸기 <br />
  바뀌었습니다.
</p>
```

- 줄 바꿈(line break)를 하는 태그이다.
- 문단 안에서 강제로 줄을 바꾸고 싶을 때 사용한다.

#### hr 태그

```html
<p>안녕하세요.</p>
<hr />
<p>반갑습니다.</p>
```

- 주제 분리를 나타내는 수평선(horizontal rule)을 긋는 태그이다.
- 이야기의 장면 전환 등 내용상 주제가 바뀔 때 사용한다.

#### input 태그

```html
<input type="text" name="userid" />
```

- 사용자가 데이터를 입력하는 폼(form) 컨트롤을 생성한다.
- type 속성에 따라 텍스트 박스, 체크 박스, 버튼 등 다양하게 변한다.

#### link 태그

```html
<link rel="stylesheet" href="style.css" />
```

- 현재 문서와 css 스타일시트 같은 외부 리소스를 연결한다.
- 주로 head 태그 안에서 사용된다.

#### meta 태그

```html
<meta charset="UTF-8" />
```

- 문서의 저자, 키워드, 문자 인코딩 방식 등 문서 자체의 메타데이터를 제공한다.

#### 작성 시 주의사항

```html
<p>
  <br />
  <img />
</p>
```

- 과거의 XHTML 방식에서는 < .../> 처럼 태그 끝에 슬래시를 붙여 스스로 종료하는 것을 명시했음.
- 현재의 표준인 HTML5에서는 붙이지 않는 것이 원칙!!
- 슬래시를 붙여도 대부분의 브라우저가 문제 없이 해석해주지만, 최신 웹 표준을 따른다면 슬래시 없이 작성하는 것을 권장

### 웹 브라우저에서 태그를 처리하는 방법

- 웹 브라우저는 HTML 문서를 읽어 화면에 그릴 때 크게 다음과 같은 과정을 거친다.
- 이 과정에서 파서(parser)는 HTML 코드를 1줄씩 읽으며 각 태그가 어디서 시작하고 끝나는지 해석한다.

```
코드 읽기(parsing) => 구조 이해하기(DOM tree) => 화면 그리기(rendering)
```

#### 일반 태그의 파싱 과정

- 파서가 < p >와 같은 일반 태그를 만나면 다음과 같은 순서로 동작한다.

1. p 시작 태그를 인식하고 돔 트리에 p 라는 이름의 새로운 노드를 추가한다.
2. p 종료 태그를 만나기 전까지 나오는 텍스트나 다른 태그를 모두 이 p 노드의 자식 요소로 넣는다.
3. p 종료 태그를 만나면 p 태그가 끝났음을 인식하고 해당 노드를 닫는다.

#### 빈 태그의 파싱 과정

- 파서가 img나 br과 같은 빈 태그를 만나면 다르게 동작한다.
- HTML5 표준 명세서에는 빈 태그 목록이 명확하게 정의되어 있어 파서는 어떤 태그가 빈 태그인지 알 수 있다.

1. 파서가 img 태그를 인식한다.
2. 파서가 갖고 있는 빈 태그 목록에 해당 태그 이름이 있는지 확인한다.
3. 빈 태그라면 img 노드를 돔 트리에 추가하고 바로 해당 노드를 완료 처리한다. /img같은 종료 태그를 기다리지 않고 바로 다음 태그로.

- 파서 입장에서 빈 태그는 자식 노드를 가질 수 없는, 그 자체로 완결된 하나의 요소이다.
- 그래서 종료 태그를 작성하게 되면 오히려 문법 오류로 간주할 수 있다.

- < br />처럼 태그 끝에 붙는 슬래시는, 파서가 이 슬래시를 무시하고 과거 XHTML 문법의 흔적으로 판단해 br 태그와 동일하게 처리한다.
- 즉, 슬래시의 유무는 빈 태그를 인식하는 데 영향을 주지 않으며 파서는 태그 이름이 빈 태그 목록에 포함되어 있는지만 확인한다.

### 정리

- HTML의 모든 태그가 종료 태그를 가지는 것은 아님.
- img, br, hr 등과 같은 빈 태그는 자체로 완결된 요소. 내부 콘텐츠 가지지 않음
- html5에서는 이러한 빈 태그를 간결하게 작성하여 파서는 태그 이름만으로 빈 태그임을 인식,
- 종료 태그를 기다리지 않고 즉시 DOM에 추가
- 또한 XHTML 스타일로 슬래시를 붙이는 스타일은 무시되며 빈 태그는 자체로 완전한 단위로 처리되어 웹 브라우저에 바로 렌더링

## 질문

Q1. HTML에서 빈 태그와 일반 태그는 구조적으로 어떤 차이가 있나요? 왜 빈 태그에는 종료 태그가 필요하지 않나요?

- 일반 태그는 시작과 종료 태그 사이에 텍스트나 다른 태그를 자식으로 담을 수 있지만, 빈 태그는 자식 노드를 가질 수 없는 그 자체로 완결된 요소입니다.
- 종료 태그의 역할이 콘텐츠의 끝을 알리는 것인데 빈 태그는 담을 콘텐츠가 없으므로 필요하지 않고, 속성만으로 역할이 정해집니다.

Q2. HTML5 파서는 img나 br같은 빈 태그를 어떻게 처리하나요? XHTML 스타일의 슬래시는 어떤 영향을 미치나요?

- HTML5 명세에 빈 태그 목록이 정해져 있어, 파서는 태그 이름만 보고 종료 태그를 기다리지 않고 즉시 노드를 DOM에 추가한 뒤 닫습니다.
- 이때 슬래시는 파서가 무시하므로 `<br>`과 `<br />`은 완전히 동일하게 처리되며, 표기 스타일의 차이일 뿐입니다.

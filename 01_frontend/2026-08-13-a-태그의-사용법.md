# 🔗 `<a>` 태그의 사용법

> 웹을 '연결된 거미줄'이라고 부르는 이유는 문서와 문서를 이어주는 a 태그에 있다. 이 태그를 얼마나 창의적이고 올바르게 사용하느냐에 따라 단순한 페이지 이동을 넘어 웹의 품질이 달라진다. 이번 절에서는 a 태그의 다양한 활용 방법과 사용 방식에 따라 생길 수 있는 취약점까지 알아본다.

## 정리

### 이미지 버튼

```html
<a href="/login">
  <img src="login-button.png" alt="로그인 페이지로 이동" />
</a>
```

이미지 버튼을 만들 때는 웹 접근성을 고려해야 한다. 스크린 리더 사용자는 이미지를 볼 수 없으므로 img 태그의 alt 속성이 결정적인 역할을 한다.

```html
<img src="login-button.png" alt="파란색 버튼" />
<img src="login-button.png" alt="로그인 페이지로 이동" />
```

첫번째 코드는 버튼의 시각적 형태만 묘사하고 있어 링크의 목적을 알 수 없지만, 두번째 코드는 alt 속성을 활용해 링크를 클릭했을때 어떤 동작이 발생하는 지 명확히 안내한다.

### 페이지 안에서 특정 위치로의 이동

```html
<h2 id="section-3">3. 결론</h2>

<a href="#section-3">결론으로 바로 가기</a>
```

a 태그는 같은 페이지 안에서 특정 위치로 이동할 때도 사용한다. 긴 문장이나 'top으로 가기' 버튼처럼 스크롤 없이 원하는 위치로 바로 이동하는 탐색 구조를 만들 때도 유용하다.
위와 같이 이동시키고 싶은 요소에 고유한 id 속성을 부여하고 href 속성에 목적지를 지정하면 클릭시 해당 위치로 이동한다.

a 태그를 사용해 페이지 안의 특정 섹션으로 이동할 때는 사용자 경험과 관련해 주의할 점이 있는데, 페이지 내 이동 링크는 문서 구조의 정확성에 크게 의존한다.
만약 href에 지정된 id가 페이지에 존재하지 않거나 오타가 있다면 링크는 작동을 하지 않거나 의도치 않게 페이지 상단으로 이동해 사용자를 혼란스럽게 할 수 있다. 따라서 목적지 id가 정확히 존재하는지, 대소문자까지 일치하는지 확인해야 한다.

### 자바스크립트 실행

```html
<a href="Javascript :myFunction();">함수 실행</a>
```

a 태그를 클릭했을 때 특정 자바스크립트 함수를 실행시키는 것도 가능하다.
과거에는 위와 같이 Javascript: 프로토콜을 href에 직접 넣어 사용했다. 이 방식은 현재 거의 사용하지 않는 오래된 패턴이며 보안상 위험이 큰 구조이다. href 속성에 사용자 입력값이 필터링 없이 포함되면 크로스 사이트 스크립팅(XSS) 공격을 실행할 수 있는 통로가 된다.

```html
<script>
  document
    .getElementById("action-link")
    .addEventListener("click", function (event) {
      event.preventDefault();
      myFunction();
    });
</script>
```

a 태그를 사용해 자바스크립트를 실행할 때는 위와 같이 href는 무력화시키고 자바스크립트 이벤트 리스너로 기능을 연결하는 것이 안전한 표준 방식이다. 다만 페이지 이동이 목적이 아닌 버튼 동작이 핵심이라면 button 태그를 사용하는 것이 시맨틱 구조로서도 바람직하다.

### 키워드 강조와 검색 엔진 최적화

a 태그를 사용하면 웹 브라우저에서 텍스트가 파란 색상으로 변경되고 밑줄로 강조되는 효과가 있다. 이렇게 강조되는 텍스트를 앵커 텍스트라고 하며 이는 검색 엔진이 링크가 가리키는 페이지를 이해하는 데 중요한 역할을 한다.
앵커 텍스트는 링크 목적지의 내용을 압축적으로 설명하는 키워드 중심으로 작성해야 한다. 링크와 전혀 상관없는 텍스트나 '여기', '클릭'처럼 목적이 드러나지 ㅇ낳는 단어는 검색 엔진 최적화에 부정적인 영향을 줄 수 있다.

```html
<p>
  웹 표준에 대해 더 알아보려면
  <a href="/web-standards">여기를 클릭하세요</a>
</p>

<p>
  더 자세한 정보는 <a href="/web-standards">웹 표준 가이드라인</a> 문서를
  참고하세요.
</p>
```

위와 같이 코드를 작성하면 웹 브라우저에서 a 태그 안에 작은 텍스트가 파란 색상으로 표시되고 밑줄로 강조되는 것을 확인할 수 있다.

### 보안을 위한 필수 속성 rel

```html
<a href="https://externalsite.com" target="_blank" rel="noopener noreferrer">
  외부 사이트로 이동
</a>
```

a 태그를 활용해 외부 웹 사이트 링크를 새 탭에서 열 때는 반드시 rel 속성을 추가해야 한다. rel 속성은 링크된 문서와 현재 문서 사이의 관계를 나타내는 속성이다.

rel 속성은 위와 같이 사용한다. noopener는 새로 열린 탭이 기존 탭의 window 객체에 접근하는 것을 막는다. 이를 통해 탭내빙(tabnabbing) 공격을 예방할 수 있다. noreferrer는 새로 열린 탭으로 이동할 때 이전 웹 사이트의 주소 정보를 보내지 않아 사용자의 프라이버시를 보호한다.

## 요약

> a 태그는 웹 접근성, UX, 보안, 검색 엔진 최적화에 영향을 주는 핵심 요소이다. 이미지 버튼, 페이지 내 이동, 자바스크립트 실행 등 다양한 활용이 가능하지만, 적절한 속성과 이벤트 처리 없이 사용하면 접근성 처리와 크로스 사이트 스크립팅, 탭내빙과 같은 보안 취약점을 초래할 수 있다. 특히 외부 링크에는 rel 속성을 지정하고, 앵커 텍스트는 링크 목적이 명확히 설명하는 키워드 중심으로 작성하는 것이 올바른 웹 표준을 실천하는 방법이다.

- Q1. 웹 접근성과 검색 엔진 최적화를 고려하여 앵커 텍스트를 작성할 때 주의할 점은 무엇인가요?
- A. `여기`, `클릭`처럼 목적을 알 수 없는 표현을 피하고, 링크 목적지의 내용을 명확하게 설명하는 핵심 키워드 중심으로 작성해야 합니다. 이를 통해 스크린 리더 사용자와 검색 엔진이 링크의 목적을 정확히 이해할 수 있습니다.

- Q2. 외부 링크를 새 탭에서 열 때 rel='noopener noreferrer"을 사용하는 이유와 각각의 역할은 무엇인가요?
- A. `noopener`는 새 탭이 기존 탭의 `window` 객체에 접근하지 못하게 하여 탭내빙 공격을 방지합니다. `noreferrer`는 이전 웹 사이트의 주소 정보를 외부 사이트에 전달하지 않아 사용자의 프라이버시를 보호합니다.

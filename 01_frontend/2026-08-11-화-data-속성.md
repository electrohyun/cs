# 📦 `data-*` 속성

> HTML 태그에는 정해진 역할을 가진 속성만 사용해야 한다. 하지만 실제로 개발을 할 때에는 사용자 ID나 게시물 번호처럼 각 요소에 고유 데이터를 저장하고 이를 자바스크립트로 읽어야 할 때가 많다. 이를 표준 방식으로 해결하는 것이 data-\* 속성이다.

## 정리

### data-\* 속성의 의미

- data-\* 속성은 자바스크립트에서 사용할 데이터를 html 요소에 저장하는 표준 속성이다.
- 모든 HTML 요소는 HTMLElement 라는 공통된 기능을 상속받으며, 여기에는 data-\* 속성을 편리하게 다룰 수 있는 dataset이라는 속성이 포함되어 있다.
- dataset을 사용하면 data-\* 속성에 저장된 값을 자바스크립트에서 쉽게 접근하고 조작할 수 있다.

### data-\* 속성이 등장한 배경

- jQuery 시절의 .data() 메서드가 비슷한 역할을 했다.
- 그러나 이 메서드는 html 요소의 속성이 아니라 제이쿼리 내부 데이터 캐시에 데이터를 저장하는 방식이었음.
- 그 결과 돔에 데이터가 남지 않아 html만 보고서는 어떤 데이터가 저장되어 있는지 알기 쉽지 않았음.
- 때로는 id나 class 등에 데이터를 끼워 넣는 편법을 사용했으며, 이런 방식이 코드를 지저분하게 만들고 유지보수를 어렵게 만드는 요인이 되었음.

- 반면 SSR 환경에서는 클라이언트로 데이터를 전달하기 위한 표준 방식으로 data-\* 속성이 널리 사용되었음.
- SSR은 서버가 완성된 HTML을 클라이언트로 보내주었기 때문.
- 이때 게시글이나 상품 목록 같은 아이템이 고유한 데이터를 포함해야만 클라이언트 쪽 자바스크립트가 이어서 작업을 수행할 수 있었음.
- 이를 위한 가장 이상적인 표준 통로가 바로 data-\* 속성.

- data-\* 속성은 데이터 저장 역할을 명확히 분리해 예측 가능한 코드를 작성하는 데 도움을 줌.
- 단, 값이 HTML과 DOM에 그대로 노출되므로 비밀번호나 인증 토큰 같은 민감한 정보를 저장하면 안 됨.

### data-\* 속성 사용법

```html
<div id="user-profile" data-user-id="999" data-user-role="user">김길동</div>
```

- data- 뒤에 원하는 이름을 붙여 사용함.
- 케밥 케이스로 작성
- 이렇게 작성한 data 속성은 자바스크립트에서 `dataset.userId`처럼 카멜케이스로 사용

```js
const userProfile = document.querySelector("#user-profile");

console.log(userProfile.dataset.userId); // "999"
console.log(userProfile.dataset.userRole); // "user"

userProfile.dataset.userRole = "admin";
console.log(userProfile.dataset.userRole); // "admin"
```

- data-\* 속성은 HTML 요소에 자바스크립트가 사용할 추가 데이터를 저장하기 위한 표준 통로이다.
- 표준 속성을 사용하면 데이터의 용도가 명확해져 코드를 일관성 있게 관리할 수 있다.

## 요약

- data-\* 속성은 HTML 태그에 자바스크립트에서 사용할 데이터를 표준 방식으로 담는 기능이다.
- HTML에서는 data- 뒤에 케밥 케이스로 이름을 붙이고, 자바스크립트에서는 dataset을 활용해 카멜 케이스로 접근하고 수정할 수 있다.
- 과거의 비표준 속성이나 제이쿼리에서 사용했던 편법 대신 data-\*를 사용하면 코드가 깔끔하고 유지보수가 쉬우며 SSR 환경에서도 효율적으로 데이터를 전달할 수 있다.

## 질문

- Q1. data-\* 속성을 사용하는 이유와 과거 비표준 속성 사용 방식의 문제점은 무엇인가요?

- A. data-\* 속성은 HTML 요소에 자바스크립트가 사용할 추가 데이터를 표준 방식으로 저장하기 위해 사용합니다. 비표준 속성이나 `id`, `class`에 데이터를 저장하면 속성의 원래 의미가 흐려지고 코드의 일관성과 유지보수성이 떨어집니다.

- Q2. HTML에서 data-user-id처럼 케밥 케이스로 작성된 속성은 자바스크립트에서 어떻게 접근하고 수정할 수 있나요?

- A. `data-user-id`는 `element.dataset.userId`처럼 `dataset`의 카멜 케이스 프로퍼티로 접근합니다. `element.dataset.userId = "1000"`처럼 값을 할당하면 HTML 속성도 함께 수정되며, 저장되는 값은 문자열입니다.
